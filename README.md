# FeedbackOS

FeedbackOS is an AI-powered customer feedback intelligence system.

It stores customer feedback using Hindsight memory and uses Groq AI to analyze feedback history.

## Features

- Store customer feedback
- Retrieve related historical feedback
- Identify recurring customer problems
- Track how problems evolve over time
- Identify evidence of improvement
- Detect newly emerging problems
- Highlight contradictions and uncertainty
- Generate evidence-based product recommendations

## Tech Stack

- Python
- Streamlit
- Groq
- Hindsight
- Pydantic
